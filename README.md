# COVID-19 Information App

A responsive web application built using HTML, CSS, and JavaScript that uses an API to fetch and display COVID-19-related information.

## Features
- Fetches COVID-19 data using an API
- Displays information dynamically
- Simple and user-friendly interface
- Responsive design

## Technologies Used
- HTML5
- CSS3
- JavaScript
- API Integration

## How to Run
1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
